# Urban Sadness

Urban Sadness is a creative studio run by Matt and Larissa. We make websites, branding, photography, video and social media for clients.

Matt is not technical and has ADHD. Explain things in plain words, keep messages short, leave space between sections, and do things one step at a time. Use light mode for anything you design.

## Rules
- Show us drafts before anything is sent, posted or published.
- Free tools first. Ask before using anything paid, and say the price.
- Never ask us to paste passwords or API keys into the chat. Tell us where to paste them (for example Vercel environment variables) and we'll do it.
- Never guess an email address. Only use ones found on a public page.
- Read the whole email thread before advising on a client or lead.

## Email
- Verdana font. Links written as words. No bold body text. No opt-out lines. No "A/C" header lines. No attachments on a first email.

## Social
- Stories are made at 1080x1920. Reels need real footage or real motion design, never photos with a zoom. No cartoon clipart. Check the whole grid before adding posts.

## Websites
- Next.js and Tailwind on Vercel, using the frontend-design skill. Designed properly: real typography, real photography, no templated look. Check every site on a phone before we show the client. Never invent facts, reviews or claims about a client; use placeholders and ask us.
